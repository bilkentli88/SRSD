# On the Trade-off Between Stability and Responsiveness in Sequential Detection

This repository accompanies the paper:

**On the Trade-off Between Stability and Responsiveness in Sequential Detection**

## Overview

Sequential detection systems must remain stable under noisy and uncertain observations, yet respond quickly when an event begins to emerge. This repository provides code, experiment scripts, and supplementary material for studying this trade-off through the concept of **response inertia**, defined as policy-induced post-onset delay caused by stability-oriented operating logic under noisy and gradually accumulating evidence.

The repository includes:

- synthetic experiments illustrating the stability–responsiveness frontier,
- NAB-based real-data experiments,
- scripts for response-inertia analysis,
- supporting figures and supplementary material.

## Main contributions of the paper

- Introduction of **response inertia** as a form of policy-induced post-onset delay.
- A unified framework for analyzing responsiveness, false-alarm behavior, switching activity, and decision volatility jointly.
- Temporally adaptive policies that selectively relax conservativeness in delay-sensitive regimes.
- Theoretical results showing weak and, under trigger overlap, strict improvement in expected detection delay relative to matched static conservative policies.
- Synthetic and real-data evidence supporting the theory.

## Repository structure

- `src/synthetic/` — synthetic experiments and trigger-ablation studies
- `src/nab/` — NAB evaluation and response-inertia analysis
- `src/utils/` — shared utilities
- `figures/` — figures used in the paper
- `paper/` — manuscript PDF and supplementary material
- `results/` — generated summary tables and outputs
- `docs/` — GitHub Pages project site

## Reproducibility

2. Run the synthetic experiment scripts
3. Run the NAB evaluation scripts
4. Regenerate tables and figures from saved outputs
